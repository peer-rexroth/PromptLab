How PromptLab works

Overview
PromptLab lets you store reusable AI prompts with variables — placeholders that you fill in before copying. Instead of rewriting the same prompt every time, you pick values from pre-defined options and copy the finished prompt in one click.
Creating a prompt
Click New Prompt in the top bar. Give it a name and assign a category using the dropdown in the header.
Write your prompt text in the Template field. Use variables anywhere in the text, then click Sync to register them.
When you're ready, click Copy prompt — the finished text with all selected values is copied to your clipboard.
Variable types
{{name}}  Option variable — single-select. Write {{Tone}} in your template. After Sync, add options like formal, casual, humorous and click the one you want. Only the selected value is inserted.
[[name]]  Instruction variable — multi-select checklist. Write [[Instructions]] in your template. After Sync, add bullet items and check any combination. All checked items are inserted as a bullet list (• item).
((name))  Text variable — free-text input. Write ((Topic)) in your template. After Sync, type any value directly into the text field. The typed value is inserted as-is.
Tip: After writing variables in the template, always click Sync — it reads the template and creates entries for any new variables it finds. Existing variables and their options are preserved.

Escaping: Prefix any placeholder with a backslash to use it as literal text — e.g. \{{name}} is copied as {{name}} without being treated as a variable. Works for all three types. In the preview, escaped placeholders appear dimmed and italic.
Managing options
Click + Option (or + Instruction) next to a variable to add a new value.
Double-click any option pill to edit its text in place.
Drag option pills (or instruction rows) to reorder them.
The trash icon on an option variable removes the currently selected option. The × icon removes the entire variable.
Categories & filtering
Click Categories in the top bar to add, rename, recolor, or delete categories. A category can only be deleted when no prompts are assigned to it.
Use the filter chips in the sidebar to show only prompts from a specific category, or only your Favorites.
Mark any prompt as a favorite with the ★ star — either in the sidebar list or the header button when a prompt is open.
Import & export
Export saves your entire library (prompts + categories) as a .json file. Use it to back up your work or share prompts with others.
Import loads a .json file. Choose Merge to add imported prompts alongside your existing ones (duplicates skipped), or Replace to overwrite your library entirely.
Your data is stored locally in your browser (localStorage). It persists between sessions in the same browser, but is not synced across devices. Use Link file in the top bar (Chrome/Edge) to also auto-save to a local JSON file — data then persists even if browser storage is cleared. Use Export regularly to keep a backup.
